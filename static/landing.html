What's inside the notebook (the good stuff)

Three ideas, one page: employees you can invent, pipelines that pass notes to each other, and a terminal that bosses everyone around.

AI employees you invent on the spot

Every worker has a name, a role, a goal and a backstory — Widi writes scripts, Nadia hunts hooks, Rizky sketches thumbnails. Need a copywriter at 2am? Type "hire Dina in studio script" and she clocks in instantly. Give each one its own model, or let them share the house default.

Workflows that pass notes

Research → competitor analysis → strategy. Hook → script → storyboard → thumbnail. Each step reads the previous step's work, like classmates passing a note down the row — except the note gets smarter.

One terminal to run it all

Tomi, the orchestrator, actually calls functions — hiring, assigning, launching workflows — and shows you every tool call as it happens. No black box, just a very fast intern with receipts.

A report room that writes itself

Every run, every step, every deliverable lands in the Report Room — live-refreshing while the team works. Monitoring dashboards for the boss, full step-by-step output for the perfectionist. Works with any OpenAI-compatible gateway, so you pick the brains and the budget.
